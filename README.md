## 为什么归档

1. 重构了整个项目，`keys.json`与`keys.local.json` 也换了格式，当然旧版密钥文件格式可以直接粘贴到新版仓库里自动迁移。
2. 当前版本无法再通过抓包获取。请求体被一次性密钥加密，而一次性密钥则进行了非对称加密，这就导致：

   - 想拿到一次性密钥，必须挂钩子
   - 钩子不稳定，而且既然都要挂钩子了，那不如直接进模拟器内存直接挖外层密钥
3. 旧版使用了一张**硬编码的外层标记的白名单**来识别存档格式，不在白名单里的标记就会认不出来
   （提示“这个文件不像是游戏的存档”）。新版取消了白名单，改成按形状识别。

### 其他 issue 中提到的问题说明

1. 游戏更新后报 ”这个文件不像是游戏的存档“

   - 原因：存档 `content` 开头那 8 个字符是外层标记，旧版只认白名单里的值，游戏换标记后，把这个新标记加进去即可。
   - 解决办法：在 [yyjh/config/constants.py](./yyjh/config/constants.py) 中添加条目

     ```python
     # ./yyjh/config/constants.py

     SAVE_MARKER_MAP = {
        ...
        'dnkemiea': ['00073314', '00073420', '00073440'],
        'mkjfded4': ['00073460'],        # 新增一行，键是那 8 个字符，值是版本号
     }
     ```

     之后仍需从内存挖外层密钥，加完标记若仍报内层密钥，说明国际服的渠道后缀未收录，需要额外提供。
     知道后缀可以直接在keys.json里补上，其中 XXXXXXXX 就是后缀

     ```json
     {
        "runtime": "android",
        "version": "00073460",
        "key": "u52kw6lbXXXXXXXX"
     }
     ```

     或者直接让工具挖，从游戏进程内存里按后缀锚定反向推出整把钥匙，挖之前重启一次游戏并且上传存档

     ```bash
     python -m yyjh key crack
     ```
2. 洗脉等功能不准确或者有错误，没有鬼市功能

   - web 这里只是用了别人发的版本，我做了个简单的适配（ Firefox 对于 `file://` 的访问，默认设置不支持跨源，使用Chrome 就没有问题）。
   - 我能力有限，也没有更新这块打算，想修的自己修或者自己让 AI 大人来修
   - 可能的问题：

     - 自动洗脉错误，但可以手动古法洗
     - 模拟装备错误，主要是精炼序列的问题，对于小于等于80次的值没有额外处理
       导致出现，取到小于10次的无法取到的上限，泥数没有对小于等于80次的锁定进行优化等等
       不过毕竟是少数，可以古法手动看，大部分还行
   - 新版不一样了吗：

     - 新版依旧是这位作者的版本，依旧是修了适配问题，同样可以独立使用。
     - 和旧版一样，具体实现没有仔细核实，但基本的装备、洗脉功能没太大问题。

## 使用方法

### 快速启动

```bash
cd /d D:/yanyu-guanxing
python run.py
```

后续按照指引进行操作即可

### 获取存档

仅限安卓，确定可用版本为 MuMu==6.8.7 ，其他版本不保证能跑通。需要十分钟左右破解密钥。

### 抓包

安卓和iOS均可

- 模拟器请安装MT管理器，并授予管理所有文件权限
- 安装免费开源抓包工具 ProxyPin ，iOS直接去应用商店即可，安卓最好访问 [github官方仓库](https://github.com/wanghongenpin/proxypin) 的 releases 下载

抓包流程

1. 进入游戏，回到主界面，在主界面退出登录
2. 打开 ProxyPin ，开启抓包（无需开启HTTPS代理）
3. 打开游戏，登录（qq/微信/邮箱），进入区服，上传一次存档
4. 回到 ProxyPin ，停止抓包
5. Proxypin 右上角三点 —— 视图导出 —— （新版本要选择HAR格式）
   模拟器需要配合MT管理器，将结果导出至文件系统，并在文件系统中复制到MuMu共享文件夹
   即，选中右侧界面，点左上角三横 —— MuMu共享文件，长按左侧ProxyPinMM-DD_HH_MM_SS.har文件，复制过去
   打开电脑的MuMu共享文件夹，一般在`C:\Users\xxx\Documents\MuMu共享文件夹`
6. 将导出的结果传输到电脑，然后启动程序`python run.py`进行解析

## 其他说明

1. 游戏本体版本更新后，密钥需要重新挖取，。
